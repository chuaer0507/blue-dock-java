# 多语言（zh-CN / en-US）

产品与 API 错误文案支持 **中文 / 英文**。设计细节见 [docs/contract/i18n.md](../../docs/contract/i18n.md)。

## 铁律

1. **首版仅 `zh-CN` / `en-US`** — 其它 language tag（含短码 `zh`/`en`）非法；写库经 `Messages.toUserLang` 仅接受这两值
2. **禁止硬编码错误文案** — Service / Filter / Handler 不得直接写中文或英文字符串作 `message`
3. **统一走 key** — `BusinessException(code, I18nKeys.XXX, args…)`；文案在 `i18n/messages_*.properties`
4. **新增文案必须双语** — 同时改 `messages_zh_CN.properties` 与 `messages_en_US.properties`，并在 `I18nKeys` 增加常量
5. **错误码与文案分离** — `ErrorCodes` 只表语义分段；展示串由 key + Locale 解析

## 语言解析顺序

| 优先级 | 来源 | 说明 |
| ------ | ---- | ---- |
| 1 | `Accept-Language` | 标准协商；`en*` → en-US，其它回落 zh-CN |
| 2 | 默认 | **zh-CN** |

实现：`LocaleFilter` → `LocaleContextHolder`；`Messages.get(key, args)` 按当前 Locale 取值。

用户偏好：`bluedock_users.lang` 仅存 **`zh-CN` | `en-US`**（`editdata`）。**不接受** `zh`/`en`。前端登录后须按 `user.lang` 设置 `Accept-Language` 与 UI locale。

## 后端落地位置

| 构件 | 路径 |
| ---- | ---- |
| Key 常量 | `com.bluedock.common.i18n.I18nKeys` |
| 解析工具 | `com.bluedock.common.i18n.Messages` |
| 中文 | `bluedock-common/src/main/resources/i18n/messages_zh_CN.properties` |
| 英文 | `bluedock-common/src/main/resources/i18n/messages_en_US.properties` |
| Locale Filter | `bluedock-boot` → `LocaleFilter` |
| 异常出口 | `BusinessException.resolvedMessage()` / `GlobalExceptionHandler` |

## 写法

```java
// ❌
throw new BusinessException(ErrorCodes.BAD_REQUEST, "昵称长度需为 2-20");

// ✅
throw new BusinessException(ErrorCodes.BAD_REQUEST, I18nKeys.USER_NICKNAME_LENGTH);

// ✅ 带参数（MessageFormat：{0}）
throw new BusinessException(ErrorCodes.NOT_FOUND, I18nKeys.USER_NOT_FOUND_ID, userId);
```

Filter 内未登录等：

```java
Messages.get(I18nKeys.UNAUTHORIZED)
Messages.get(I18nKeys.UNAUTHORIZED_EXPIRED)
```

## 前端（bluedock-web）对齐

- UI：`packages/i18n` 运行时 `zh-CN` / `en-US`
- HTTP：注入 `Accept-Language`（与 `user.lang` 一致）
- 切语言：`api/users/editdata?lang=zh-CN|en-US` + 热切换 UI
- 主题：仅本地 `blue-dock-theme`，不写后端
- 错误展示：优先 `code` 本地映射；否则直接用响应 `message`（后端已本地化）
- 错误 key 命名可与 `I18nKeys` 同源（如 `auth.failed`）

## 反模式

```java
// ❌ ResultModel.fail 手写中英文
return ResultModel.fail(1001, "未登录");

// ❌ 只改中文 properties，漏英文
// ❌ 新增 I18nKeys 却不进 properties
// ❌ 把用户可见文案写进 ErrorCodes 注释以外的代码常量串
```
