# 即时通讯 — 权限

## 会话角色

| 角色 | 适用范围 | 能力 |
| ---- | -------- | ---- |
| 群主 `ownerId` | `group_type=user` 普通群 | 改名、加人/踢人、任命管理员、转让、解散 |
| 群管理员 `deputyIds` | 普通群 | 加人/踢人（不可踢群主）、部分设置 |
| 成员 | 所有群 | 发言（未禁言时）、退出（自动群可能受限） |
| 单聊双方 | `type=user` | 对等；**真人不可向机器人单聊发消息**（可打开查看推送） |

## 自动维护群（项目 / 任务 / 部门 / 全员）

- 成员随源数据同步，**不能**随意拉非成员进群
- 项目群角色镜像 `ProjectUser.owner`
- 全员群改名等仅系统管理员
- 解散跟随源对象生命周期，不提供独立「解散项目群」入口

## 消息操作

| 操作 | 谁可以 |
| ---- | ------ |
| 撤回自己的消息 | 发送者（受 `messageRecallLimit`；0=不限；自聊与机器人作者豁免） |
| 撤回他人 | 群主/管理员（若产品开启）或超管兜底 |
| 禁言 | 系统设置全局（`userPrivateChatMute` / `userGroupChatMute` / `allGroupMute`）· 会话 `bluedock_dialog_configs.is_chat_muted`；系统管理员豁免；普通群主/管理员豁免会话级与普通群全局禁言 |
| 已读回执查看 | 会话成员 |
| 匿名消息 | 按系统开关 |

## 与系统管理员

系统管理员**不**自动获得任意群的群主权；例外能力以产品约定的超管兜底为准（如强制删群）。

详见 [overview.md](overview.md)、[role-permission](../role-permission/overview.md)。
