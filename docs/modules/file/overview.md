# 文件

> 功能说明（从产品能力清单同步）。实现以 `docs/contract/api-contract.md` 与后端代码为准。

## 范围

### 概念

- **文件预览类型**
- **文件树结构**
- **文件版本历史**

### 能力（怎么做）

- 新建文件夹 / 在线文档 / 表格 / 思维导图
- 删除文件或恢复文件
- 移动文件或文件夹
- 文件公开访问链接
- 重命名文件或文件夹
- 搜索文件
- 文件协作权限（共享给他人）
- 上传文件

## 核心概念

### 文件预览类型

## 定义
文件预览指在浏览器内不下载即可查看的能力。BlueDock 不同文件类型走不同预览管线，依赖不同插件。

## 浏览器直接预览（无需插件）
- **document**：内置在线文档（Markdown 渲染器）
- **txt / code**：纯文本与代码高亮
- **picture**：jpg / png / webp / gif / bmp 直接渲染
- **mind**：思维导图（需 minder 插件，但产品默认随包提供）
- **drawio**：流程图（需 drawio 插件）

## 需安装插件预览
- **word / excel / ppt**：内置类型，但实际渲染由 OnlyOffice 完成，需 office 插件
- **pdf / cad / ofd / tif** 等：由 fileview 插件提供
- **wps**：fileview 插件

## 不支持预览的类型
- **archive**（zip / rar / 7z 等）：只能下载，无在线解压
- **media**（mp3 / mp4 / mov 等）：从文件入口直接下载，预览能力依赖浏览器原生
- **axure（rp）**：仅记录类型，需用 Axure 客户端查看

## 在线编辑 vs 仅预览
- 在线编辑：document、word/excel/ppt（office 插件）、mind、drawio
- 仅预览：pdf、其他 fileview 支持的类型
- 编辑权限受 FileUser 权限位（读写 / 只读）控制

### 文件树结构

## 定义
BlueDock 的文件以树形结构组织：每个文件或文件夹（type=folder）通过落库 `parent_id`（API wire `parentId`）指向父级，根目录为 0。

## 关键属性
- **parentId**（落库 `parent_id`）：直接父文件夹 ID，0 表示根
- **type=folder**：文件夹本身也是 File 表的一条记录
- **userId**：拥有者（与共享文件夹一致时表示共享根）
- **isShared**（落库 `is_shared`）：是否已生成外链分享

## 容量限制
- 单文件夹直接子项数量上限 300（含子文件夹）
- 整树深度无强制上限但超过 10 层不推荐
- 共享文件夹最多 100 个共享成员

## 与「项目任务文件」的区别
- 文件树：用户的网盘，独立功能
- 项目任务文件：附在任务下的附件（`project_task_files` 表），不进入文件树
- 两者完全隔离，互不可见

## 文件类型枚举
folder（文件夹）/ document（在线文档）/ mind（思维导图）/ drawio（流程图）/ word / excel / ppt / picture / archive / pdf / txt / code / media 等。

### 文件版本历史

## 定义
对支持在线编辑的文件，每次保存都会在 `file_contents` 表插入新记录（FileContent），形成版本历史。文件本身（File 表）只指向最新版，但通过 `whereFid + orderByDesc('id')` 可查到所有历史版本。

## 关键属性
- **fileId**（落库 `file_id`）：所属文件 ID
- **content**：JSON 元数据，包含真实存储路径 url、类型 type、扩展名 `extension`
- **text**：提取出的纯文本（用于全文检索）
- **size**：本版本大小（字节）
- **userId**：本次保存人
- **createdAt**：保存时间

## 哪些文件类型有版本
- document（在线文档）
- word / excel / ppt（通过 OnlyOffice 在线编辑）
- mind（思维导图）
- drawio（流程图）

## 哪些文件类型没有版本
- 上传二进制（pdf / archive / picture / media 等）覆盖上传只保留最新一版
- folder 本身无内容，无版本

## 查看与恢复
- 入口：文件预览页 / 编辑页 → 顶部菜单「历史记录」
- 列表显示每一版的保存人头像 + 时间 + 大小
- 选某一版可「预览」或「恢复」（恢复 = 把该历史版复制为新的最新版，保留中间版本）

## 与"文件协作锁"
BlueDock 在线 Office 编辑通过 OnlyOffice 提供多人协作，多人编辑同一文档时由 OnlyOffice 自身的协同逻辑保证一致性，并在最后一个编辑者关闭后回写一版到 FileContent。

## 不支持 / 边界

- "文件名长度 2-100 字符；不能包含特殊字符（反斜杠、斜杠、冒号、星号、问号、双引号、尖括号、竖线）"
- mind / drawio 需要管理员在应用市场安装 minder / drawio 插件，否则无法保存
- office 类（doc/xls/ppt 等）预览需要管理员在应用市场安装 office 插件（OnlyOffice）
- word / excel / ppt 新建空白文件需要 office 插件（OnlyOffice）
- 「文件」页内置搜索只匹配文件名 / 文件 ID，不搜文件内容
- 一次最多删除 100 个文件 / 文件夹
- 一次最多移动 100 个项目
- 不支持「版本备注」字段（只看保存人 + 时间 + 大小）
- 不支持上传文件夹后保留文件夹下原有空目录（空目录会被忽略）
- 不支持批量重命名（一次只能改一个）
- 不支持跨用户的全局共享根目录
- 不支持软链接 / 快捷方式（一个文件只能在一个位置）
- 不能在已有共享文件夹内的子文件 / 子文件夹单独再共享（嵌套共享被拒绝）
- 不能改扩展名（如 docx 改 pdf），扩展名由文件类型决定
- 不能移到自己的子文件夹（会循环引用）
- 共享只能选「只读」或「读写」两档，没有「评论」「仅看链接」等中间档
- 共享后文件夹内所有子文件的拥有者保持不变（不会迁移）
- 其他格式（PDF / CAD / OFD 等）预览需要 fileview 插件
- 删文件夹会级联删除其内所有文件与子文件夹
- 删除会同时清理共享配置（FileUser）和分享链接（FileLink）
- 刷新链接后旧链接立即失效，没有过渡期
- 单个共享对象最多 100 个成员
- 单个文件夹下最多 300 个直接子文件 / 子文件夹
- 单个文件夹下最多 300 个直接子项
- 单个文件夹直接子项上限 300，超出会报错
- 单次返回最多 100 条，默认 50 条
- 只读或仅可读写（非创建者）的共享成员无删除权限：删除入口在界面被禁用，后端 file/remove 也会拒绝并返回「仅限所有者或创建者操作」
- 同一用户在同一目录下并发上传会自动排队（避免数据库死锁），慢但不会丢
- 同目录下若已存在同名同后缀文件，系统会自动加 (2) / (3) 后缀（不会覆盖也不会报错）
- 含共享内容的文件夹不能移入共享文件夹（同上）
- 已共享的文件 / 文件夹不能移入另一个共享文件夹（避免共享嵌套）
- 搜索范围 = 自己的文件 + 共享给自己的文件，不跨他人私有空间
- 文件内容搜索需走全局搜索（Manticore 索引），仅文档类与文本类文件被索引
- 文件删除采用软删除；可通过 `GET /api/file/trash` 列出、`GET /api/file/restore?id=` 恢复（含子树；父级仍删则挂到根；共享不自动恢复）
- 文件名长度仍受 2-100 字符限制
- 普通上传文件覆盖后只会替换最新版，无完整历史
- 未安装对应插件时打开会提示「未安装」，但仍可下载
- 没有版本数量上限，但定期清理由系统设置决定
- 版本历史仅对在线编辑类（document / word / excel / ppt / mind / drawio）有效
- 移到共享文件夹后，文件拥有者（userId）会改为共享根的拥有者
- 视频 / 音频不在文件预览里直接播放，会触发下载
- 跨设备续传不可用：续传索引存浏览器 localStorage，仅本机本浏览器内有效
- 链接不支持设置访问期限 / 密码 / 访问次数上限
- 链接路径中包含 file_id + userId + 随机串，base64 编码，不要泄露
- 链接默认仅登录用户可访问；游客访问需要在链接设置中显式打开 guest_access
