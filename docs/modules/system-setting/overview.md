# 系统设置

> 功能说明（从产品能力清单同步）。实现以 `docs/contract/api-contract.md` 与后端代码为准。

## 范围

### 能力（怎么做）

- AI 机器人与默认模型
- AI 模型配置
- 任务自动归档设置
- 群组与私聊禁言设置
- 签到规则设置
- 列模板（创建项目预置列）
- 端到端加密设置
- 单文件上传大小限制
- 文件设置（打包下载权限）
- 对象存储引擎（OSS，管理端可配）
- 邮件 SMTP（管理端可配，同 file/oss）
- AI 模型 Key（`aiBotSetting`，管理端可配，同 file/oss/email）
- 会议 Agora / APP 推送（管理端可配；密钥掩码同 OSS）
- 通用设置
- 消息撤回与编辑时长上限
- 密码策略设置
- 任务优先级配置
- 注册策略设置
- AI 任务自动分析设置
- 任务可见性选项显示策略
- 第三方接入（LDAP 入口）
- 待办设置权限
- 视频转码与压缩设置

## 不支持 / 边界

- SYSTEM_SETTING=disabled 时不能修改
- SYSTEM_SETTING=disabled 时所有系统设置都不能改（演示环境常用）
- SYSTEM_SETTING=disabled 时禁止保存
- SYSTEM_SETTING=disabled 时配置不可修改且会被部分打码显示
- aiBot 设置不影响群机器人 @ 时使用的模型，群机器人有独立绑定
- v1.4.35 起旧接口 setting__ai 已废弃，AI 模型配置全部迁移到 AI 助手应用的设置面板
- 三个开关相互独立，不会联动；要全静音得分别关
- 不会回溯分析历史任务，只对新建后进入待分析队列的任务生效
- 不会回溯处理历史上传的视频，只对新上传文件生效
- 不区分私聊 / 群聊：是否走 e2e 取决于接口，而非会话类型
- 不安装 ai 插件，「AI 助手」应用不出现
- 不支持 Jitsi、Zoom、WebRTC 自建等其他后端，目前仅适配声网
- 不支持按优先级自动指派负责人 / 自动通知
- 不支持按部门 / 项目分类区分模板
- 不支持给不同部门设置不同打卡规则，全公司共享一套
- 不支持自动按公历节假日跳过打卡
- 不支持自定义正则、最小特殊字符数等细粒度规则，只有 simple / complex 两档
- 不是「公开 / 项目内 / 仅负责人」三选一，只有 open / close 两档
- 不能按用户 / 部门设差异化阈值，全局生效
- 不能给单个项目自定义独立优先级，全局共享一套
- 不能选目标分辨率 / 码率，参数固定
- 临时帐号一旦创建无法在线一键转为正常帐号
- 保存时空 list 或 list 中没有合法条目会报「参数错误」/「参数为空」
- 修改模板不会影响已创建项目，仅影响后续新建
- 修改策略不会触发存量用户重置密码，存量密码继续可用
- 关键词搜索不能搜到加密传输中的密文内容（已落库的文本可被搜索）
- 关闭后任何人都不能"批量给一群人设 todo"，包括非自己的成员
- 关闭签到（open=close）时 key 会自动轮换（再开启需要重新分发设备）
- 单文件下载没有黑白名单，权限全部由文件本身的可见范围决定
- 子任务不会被独立归档，只看顶层任务（parent_id = 0）
- 密码长度上限固定 32 位，无管理后台开关
- 已有任务的实际可见性数据不受本开关影响
- 归档天数限制 1-100 天，超出范围保存时报错
- 当前「第三方接入」仅集成 LDAP，没有 OAuth / SAML / 钉钉 / 飞书的同义入口
- 必须填 `appId` 和 `appCertificate` 才能保存为「open」，否则报「请填写基本配置」
- 提前 + 延后时间之和必须 < 24h-工时，否则报「提前和延后时间设置存在重叠」
- 撤回 / 编辑消息的时长限制由 `messageRecallLimit` / `messageEditLimit` 决定，与 e2e 无关
- 时长以分钟为单位整数，不支持小时 / 秒级粒度
- 普通用户调用保存接口会被拒绝（仅 admin）
- 未安装 ai 插件时菜单不出现，调用接口会直接抛错
- 未安装 ai 插件时，分析逻辑直接跳过，不会有任何产出
- 模板只控制「初始列」，不能预置任务卡、流程、负责人等其他内容
- 注册策略只有 open / close / invite 三档，不支持按邮箱域名白名单
- 测试连接（`testLdap`）若管理员 DN 或密码错误，前端只会显示「验证失败」，不会带具体 LDAP 错误码
- 留空 = 默认 1G（前后端兜底一致）；填具体值后取该值；仍受 Nginx / 网关服务级限制
- 留空（视作 0）= 不限制，不是「禁止撤回」
- 端到端加密只对一组固定的敏感接口生效，不会对历史消息追溯加密
- 系统开关 = open 但项目级开关 = close 时，该项目的任务也不会被分析
- 系统管理员永远可发言，不受任何开关限制
- 自动归档天数限制为 1-100 天，超出会报错
- 自己给自己设 / 取消 todo 不受开关限制
- 该字段只控制任务详情 UI 上"可见性"控件是否常驻显示，不直接改任务的可见范围
- 该接口在 SYSTEM_SETTING=disabled 环境会拒绝写入
- 该限制只控制单个文件大小，不是磁盘配额或总量上限
- 超过设定时长后所有人都不能撤回 / 编辑该消息，系统管理员也不例外
- 转码 / 压缩失败时回退保留原文件，不会丢消息
- 这是消息→待办（聊天里把某条消息变成 todo）权限，与项目任务无关
- 这页只控制「文件夹打包下载」的访问名单，不控制单文件下载
- 邀请码留空会自动生成随机码，不能完全关闭"凭码注册"模式
- 邀请码留空保存后系统会自动生成一个随机码，不能完全关闭"凭码可注册"模式
- 部门群、项目群等系统群不受 user_group_chat_mute 控制，永远可发言（除非加入全员群禁言）
- 配置入口不在「系统设置」菜单，而在「AI 助手」应用内的设置面板（仅管理员可见）
- 项目自身若设了"自定义归档"（archive_method=custom），系统级开关对该项目不生效
