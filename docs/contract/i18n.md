# 多语言与错误码

## 多语言（zh-CN / en-US）

| 层 | 约定 |
| -- | ---- |
| API `message` | 按请求语言返回中文或英文 |
| 客户端 UI | `bluedock-web` 文案包运行时 key `zh-CN` / `en-US`，key 稳定 |
| 服务端枚举展示名 | 存 code，展示名由客户端或 i18n 表解析 |

### 语言解析顺序（后端）

1. `Accept-Language`
2. 默认 **zh-CN**

个人设置 `users.lang` 仅存 **`zh-CN`** 或 **`en-US`**（`editdata` 写入；其它 tag 一律 `user.lang_invalid`）。  
**不接受**短码 `zh` / `en`，不做存量读侧兼容。  
**前端**登录后应按 `user.lang` 同步设置 `Accept-Language` 与 UI locale（本地 `i18nextLng`）。

### 后端实现

| 构件 | 位置 |
| ---- | ---- |
| 文案资源 | `bluedock-common/src/main/resources/i18n/messages_zh_CN.properties`、`messages_en_US.properties` |
| Key 常量 | `com.bluedock.common.i18n.I18nKeys` |
| 解析 | `com.bluedock.common.i18n.Messages`（`toUserLang` → `zh-CN`/`en-US`） |
| Filter | `LocaleFilter`（`Accept-Language`） |
| 异常 | `BusinessException(code, messageKey, args…)` → Handler 解析为本地化 `message` |

业务代码**禁止**硬编码中文/英文错误串，统一抛 `I18nKeys.*`。  
Agent 强制规则见 [`.agents/rules/i18n.md`](../../.agents/rules/i18n.md)。

### 前端（bluedock-web）约定

本仓库为后端；前端仓应对齐：

1. UI 文案包：`packages/i18n`，运行时 `zh-CN` / `en-US`（目录可仍为 `locales/zh` · `locales/en`）
2. 错误码：优先用响应 `code` 映射本地文案；若无映射则直接展示 API `message`（已随语言本地化）
3. HTTP 客户端默认带 `Accept-Language: zh-CN` 或 `en-US`（与用户设置一致）
4. 用户改语言：调用 `api/users/editData?lang=zh-CN|en-US`，并立即切换 UI locale + 请求头
5. 支持语言首版仅 **zh-CN**、**en-US**；短码 `zh`/`en` 与其它 tag 均非法
6. 主题仅本地存储（`blue-dock-theme`），不写 `users` 表

示例（前端 locale）：

```json
{
  "common.ok": "确定",
  "common.cancel": "取消",
  "auth.login": "登录",
  "project.create": "创建项目"
}
```

```json
{
  "common.ok": "OK",
  "common.cancel": "Cancel",
  "auth.login": "Sign in",
  "project.create": "Create project"
}
```

Key 命名：`domain.action`，与后端 `I18nKeys` 可共用同一套错误 key（如 `auth.failed`）以便共享包。

## 响应信封

```json
{ "code": 0, "message": "", "data": {} }
```

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 非 0 | 业务失败（HTTP 通常仍 200）；`message` 已按请求语言本地化 |

## 错误码分段

| 段 | 模块 |
| ---- | ---- |
| 1000–1099 | 通用（参数、未登录、无权限） |
| 1100–1199 | 账号 / 鉴权（另：`-2` token 过期、`-3` 需验证码、`-11` 公钥失效） |
| 1200–1299 | 项目 |
| 1300–1399 | 任务 |
| 1400–1499 | 会话 / 消息 |
| 1500–1599 | 文件 / 上传 |
| 1600–1699 | 系统设置 / License / LDAP |
| 1700–1799 | 搜索 / AI |
| 1800–1899 | 报告 / 会议 / 签到 |

具体码：`bluedock-common` 的 `ErrorCodes`。文案 key：`I18nKeys` + `i18n/messages_zh_CN|en_US.properties`。**禁止**魔法数字散落 Controller。

## 权限不足

统一风格：`error.forbidden` / 业务 denied key；可选 `data.reason`。勿泄露他人私密字段名。

## 联调检查

| 步骤 | 期望 |
| ---- | ---- |
| `Accept-Language: en-US` 调错误接口 | `message` 为英文 |
| `Accept-Language: zh-CN`（或缺省） | `message` 为中文 |
| `editdata?lang=en-US` 后前端切 en-US | UI + 后续 API 英文 |
| `editdata?lang=en` 或 `zh` | 失败（`user.lang_invalid`） |
